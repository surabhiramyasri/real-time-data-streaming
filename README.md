 Real-Time Data Streaming



Project Overview



This project demonstrates real-time data streaming using Python. It continuously generates weather-related data such as temperature, humidity, and rainfall at regular intervals.



** Objectives**



**\* Generate real-time weather data**

**\* Display streaming data continuously**

**\* Understand the basic concept of real-time data streaming**

**\* Analyze continuously changing data values**



**Technologies Used**



**\* Python**

**\* Random**

**\* DateTime**



** Data Fields**



**\* Time**

**\* Temperature**

**\* Humidity**

**\* Rainfall**



**How to Run**



**1. Open Command Prompt in the project folder.**

**2. Run:**



**```bash**

**python real\_time\_streaming.py**

**```**



**3. The program displays new data every 2 seconds.**



**## Output**



**The system continuously displays real-time weather data including temperature, humidity, rainfall, and timestamp.**



**Conclusion**



**This project provides a simple demonstration of real-time data streaming and helps understand how continuously generated data can be captured and displayed.**
